# Cómo se consiguen las runas

Estado a 2026-10-09. Las ocho runas de mago indicadas reproducen la adquisición de mundo de SoD con objetos reales. Las filas restantes describen la adquisición implementada o provisional; Lifebloom, Nourish y las nuevas runas de paladín y chamán se desbloquean con objetos comprados al Grabador. En SoD real cada runa se consigue en el mundo (misión, objeto, vendedor o evento), pero muchas fuentes aún no se han verificado.

La columna de Wowhead enlaza por el id del hechizo de SoD, que es el mismo que usa este servidor: `https://www.wowhead.com/classic/spell=<id>` muestra el hechizo y, en su pestaña, qué objeto lo enseña y dónde se consigue. **wago.tools no trae tablas de botín ni de misiones.** Para el paladín, las correspondencias de objetos y fuentes de SoD se han contrastado con `docs/runas/fuentes-sod.json`; las fuentes de SoD no disponibles en este core se señalan como pendientes. Para el chamán, las correspondencias de objetos se tomaron del catálogo local; Wowhead no respondió por DNS durante esta tarea. La adquisición del resto de clases aún no se ha verificado runa a runa.
