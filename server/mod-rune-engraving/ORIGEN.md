**Motor de runas.** Copia propia («vendored») de https://github.com/mod-sod/mod-rune-engraving.

- Commit de partida: `f436ef64fcd656683a00ae9c913b6ba7ae910688` (2026-06-22)
- Licencia: `LICENSE` con texto de **GPL v3**, pero las cabeceras de los fuentes dicen «GPL v2 o posterior» (comprobado el 2026-10-05). Copiado sin historial de git.
- Se copia aquí (y no se usa directamente desde `upstream/`) para que el proyecto sea
  reproducible aunque el original desaparezca: tiene 0 estrellas y 0 forks y está parado.
- Mantiene el nombre original porque el nombre del directorio fija el de su cargador
  (`Addmod_rune_engravingScripts`); renombrarlo exigiría tocar código sin necesidad.
